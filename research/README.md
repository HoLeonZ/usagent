## 口径(改之前先读理由)

| 项 | 取值 | 为什么 |
|---|---|---|
| 价格 | **双价格体系**(§3(b)):`close` 等用分红回补价喂指标;`raw_*` 用 as-traded 价做止损/跳空/市值/现金 | 复权价只对**比例型**指标无害;止损止盈触发与现金记账必须用物理价格。审计实测:全部跑在复权价空间时,复权因子(含**未来**分红)使 VNOM 一笔被乐观 0.92pp |
| `amount` | `volume × raw_close` | 代理量。**必须用 as-traded 价**:`ohlcv` 无成交额列,而 E 条件拿它比**绝对美元阈值**,用复权价会让「T 日能不能进池」变成 T 之后分红的函数(实测 740 个就绪格判定被翻转) |
| 价格完整历史一次载入 | 非逐窗口载入 | 逐窗口时每个窗的 MA120 只拿到本窗+400 自然日;全历史载入预热更充分。**是等价变换**:全体算完再切片 == 带足预热的逐窗算(由 `test_causality` 钉住) |
| 可评估窗口 | 由**数据算出**(`panel.first_signal_date`) | `mom120` 需 121 根 K 线,前 120 个交易日是预热。**边界不能写死常量** —— 写死之后换一份数据就会把预热期算进 CAGR 分母,且无人报警 |
| 成本 | 双边 5bp,常数在 `core/costs.py` **唯一定义** | 美股无印花税。IBKR Lite 佣金 $0 + SEC §31 + FINRA TAF。CLI 的 `--cost-bps` 只做覆盖,默认读 preset(§2(b) 要求常数恰好定义一次) |
| 滑点 | `core/costs.py` 的 `ATR_SLIP_SCALE`,preset 显式声明 | §4(c) 要求滑点是 **f(ATR, 参与率)**:`slip = scale × atr_pct × sqrt(该单股数/本 bar 成交量)`。此前是**零滑点**,且公式里参与率被写成字面量 1.0 |
| 分红 / 拆股 | 分红**显式入账**到 Free_Cash,并计入该笔净盈亏;拆股不重复缩放 | §3(c):现金分红必须触发一笔物理现金存入。库里的价本身已是拆股后价位(`series.source_is_split_adjusted` 实测),再乘一次就是造 +892% 假巨阳 |
| **取池** | preset 的 `universe` 是 **PIT 声明**(`research/universe.py`):`liquidity` 模式=截至 T 的滚动成交额门槛,因果;`membership` 模式=显式成分区间表 | §3 PIT Mandate。此前 `universe` **引擎根本不读**、池子="DB 里恰好有什么"(而名单来自**今日**快照)⇒ 幸存者+前视。现在资格是**必填**列,信号/族/基准/筛选四处的消费点缺列即 fail-fast |
| **组合层风险** | `max_weight` 单名权重、`max_heat` 组合热风险(Σ 计划风险/权益)、`max_drawdown_halt` 回撤停机 | 审计 D1/D2:修之前组合层**没有任何聚合量**(只有"数仓位个数")。不设上限时引擎照样输出 `peak_heat`/`peak_name_weight`/`pct_days_halted` —— "没设上限"不是隐形事实 |
| **仓位可审计** | 每笔记 `sizing_cap`(policy/volume_cap/max_weight/max_heat/cash)与 `risk_frac` | 审计 D3:现金闸门曾**静默**改写声明风险(5% → 0.6%),报告里看不出来 |
| **价差** | `spread_model=corwin_schultz`:用日线 high/low 估**逐日**价差(因果、滚动中位平滑),两侧各付半价差 | 审计 E1:成本模型此前只有规费+冲击滑点,**没有买卖价差**——而它是**尺寸无关**的那一半。该估计量**系统性低估**(实测注入 100bp 估回 72bp)⇒ 给出的是**下限** |
| **止损穿价** | `sl_overshoot`(默认 0)+ 逐笔记 `sl_penetration` | 审计 E2:盘中触发止损一律按触发价成交、与穿价深度无关。实测穿价中位约 100bp / p90 约 176bp,θ∈[0,1] 让头条差数个百分点 —— θ 的正确值需实盘标定(台账 E2b) |
| **窗口末尾** | `liquidate_at_end`(默认开):最后一根收盘价清算,reason=`eod` | 审计 C5:不清算时头条(权益含浮盈)与 E[R](只算已平仓)**来自两个样本**。停牌/无 bar 的仓位按 §1 **不造成交**,代之以 `samples_aligned=False` 显式报出 |
| **DSR 口径** | `metrics.deflated_sharpe_from_returns(收益序列, n_trials, periods_per_year)`:T/偏度/峰度/自相关全部从**同一条序列**派生 | 审计 B3:此前四个调用点各传各的(交易日数/成交笔数/月数),且**从不传高阶矩**(等于假设 iid 正态)。实测日收益偏度 +1.46、峰度 40、自相关 +0.20 |
| **多比较校正** | `metrics.benjamini_hochberg` + `bonferroni_t_threshold`;因子判词先看整族再下 | 审计 B4:点比较的 |t|≥2 在族规模下**不成立**。预注册判据**不事后放宽**,校正的产物是"还剩几个" |
| **holdout 台账** | `research/holdout.py`:同一窗口二次 claim **默认拒绝**,给理由才放行且理由入账 | 审计 B1:"这段窗口没参与过选择"此前只写在注释里。台账落在 `research/results/`(run artifact) |
| **归因** | `research/factor_model.py`：对 [market, mom, lowvol] 做**带 HAC 标准误**的回归 + 跟踪误差/IR；`run_baseline --attribution` | 审计 C4:"超额"此前**只有 CAGR 之差**，回答不了"这份收益里有多少是风格 beta"。因子代理从**面板自己**构造（横截面动量/波动的多空三分位），月频再平衡、划分只用 ≤ 再平衡日的数据。⚠️ 无价值因子（无基本面）与规模因子（市值快照非 PIT） |
| **口径自报** | 报告头由 `core/preset_contract.spec_header()` 生成,CLI/HTML/JSON **共用同一个函数** | 审计 E5:读者此前只能去读 preset 源码,或默认"没价差、没上限"。**否定事实必须显示**("滑点关闭"/"未设上限"/"不清算") |
| 纪律 | `n_comparisons` 在 `presets.py`(单一事实来源) | CLAUDE.md §5 Iterative-Tuning Accounting。本文不复述数值 —— §7 要求文档只写怎么复现、不写曾观测到什么 |

## 执行语义(可移植部分 + 明确删除的 A 股件)

**保留**:信号 T 收盘 → T+1 开盘入场;`intraday_tiebreak = "sl_first"`(同 bar 双触发按最坏情况);
gap 跳过止损按开盘价成交;成交量上限 `Bar_Volume × 10%`,超出 IOC 丢弃、现金立即回 Free_Cash;
排序 `score = mom120` 降序、超容量当 T 丢弃不排队;`max_positions` 由 preset 显式声明。

**结算隔离(§2(d),2026-10-15 修复)**:**当日入场的预算与容量取自「上一交易日收盘」的
账本快照** —— 同日卖出所得、同日出场释放的仓位槽,当日一律不可用。主循环是「先平仓
(盘中价)再开仓(开盘价)」,开盘在时间上早于盘中;不隔离就等于用几小时后才产生的钱付
几小时前的账。审计实测：旧实现下 12m preset 有相当比例的成交靠的就是这笔钱；隔离后
它的 CAGR **大幅下降**，并低于它自己声称达到的目标。

**删除**(理由见设计文档 §3):涨跌停不可成交 / 100 股整手 / 印花税。
⚠️ 此前把「T+1 可卖性」与「三池保证金」一并列为删除项 —— 那一并删掉的正是**现金隔离**,
是上面那条修复要补回来的东西。美股语境下要保留的是「未结算资金不得当日复用」,
不是 A 股 T+1 的可卖性约束。

**偏离 hiagent §2 的一处**:`all-in` → `risk_budget`(preset 里 `risk_per_trade` 在场即生效)。
§2 的 all-in 与「窄止损」耦合,详见 `presets.py` 的注释与 `results/BASELINE.md` §1C。
`position_fraction` 现在是**必填契约字段**(它是关掉风险预算后的兜底预算)。

## 筛选器 `screen.py`

把 596 只收窄成人能过目的候选。**但它同时在测量自己。**

```bash
# 解释器：本项目不假设某一台机器的路径。用 `PY=python3`（或你自己的 venv 解释器），
# 依赖版本见 requirements.txt。
PY=${PY:-python3}

# 1) 先看各层条件到底有没有携带信息(先做这个)
$PY -m research.screen --measure

# 2) 出候选清单(输出末尾**永远**附带该层实测基准率)
$PY -m research.screen --tier trend_pullback --top 20
$PY -m research.screen --measure --horizon 5     # 换持有期
```

### 门槛按族规模折减(§5(c))

判词门槛是 **Bonferroni 校正**后的:一次 `--measure` 要对 4 个层级各下一次判词,
门槛因此从 1.96 抬到 2.498(默认族规模 = 被检验的层级数 4)。换 `--horizon` / 换窗口
再跑一次,族就更大 —— 用 `--family-size` 把它累加进去(例如 4 层 × 3 个 horizon → 12,
门槛 2.865)。输出里会同时印出当前族规模与门槛。

### 凭证落盘（`--out`）

```bash
$PY -m research.screen --tier trend_pullback --out results/candidates.json --note "为什么跑这一次"
```

产物带 **ts（带时区）/ git sha / 工作区是否脏 / 数据 vintage** + 口径参数 + 清单 + 同层基准率，
并标 `valid`：读数无效（样本不足/基准不是有限数）时写成 `valid=false` 并给理由 ——
不许把「有凭证」与「凭证可信」混为一谈。

### 这个工具不做什么

**它不预测方向。** 判据是「相对全池基准、并已按重叠采样折减的 t 值」。截至 2026-10-14,
四个层级都落在「与随机选票无统计差别」区间内 —— **具体数值请自己跑 `--measure`**,
本文不复述(§7:文档写怎么复现,不写曾经观测到什么)。所以:
清单的价值在于把 596 只收窄到几十只供你过目,**方向判断得由你补**。

### 两条口径陷阱(输出里也写了)

1. **绝不看"均值是否 > 0"。** 样本覆盖一段上涨市,全池基准的绝对均值必然为正 ——
   任何纯多头筛选的均值都会是正的。判据只有"vs 基准",而基准本身随窗口变,
   所以它同样不该被写死进文档。
2. **重叠采样必须折减。** h 日持有期逐日采样,独立观测数约为 n/h,均值的
   标准误被低估约 sqrt(h) 倍。不折减的 t 会虚高(报告 §3.5 有这张膨胀系数表)。
   `screen.py` 同时给出 `t_raw` 与按 sqrt(h) 折减后的 `t_adj`,**判读只看后者**。

## 已知方法学限制(不要当优点读)

1. **没有独立期。** 库只有 3 年(可评估 2.51 年),不存在一段"从未参与迭代"的长期历史。
   最多只能 train/holdout 对分 —— 能防过拟合,防不了"整段窗口恰好是牛市"。
2. **幸存者偏差未消除。** 股票池是今日快照;绝对 CAGR 应读作上界。
3. **基准是日度再平衡等权指数**,非严格 buy-and-hold;它高估的是对照项。
4. **`t_expectancy` 在 R 退化时无判别力**(固定止损让每次止损 ≈ −1R)。`run_baseline.py`
   会检出并拒绝该行 t 值。

## 按预注册协议挖 preset(`wfv_search.py`)

```bash
# 解释器：本项目不假设某一台机器的路径。用 `PY=python3`（或你自己的 venv 解释器），
# 依赖版本见 requirements.txt。

```

**为什么要另起一个文件**:旧的 `stage1/stage2` 是「在同一窗口取 argmax、再对胜者在同一窗口
精调退出参数」。审计实测出它的两个后果:胜者的**五个参数全部落在网格边界**上;空信号配置被
记成 `+0.0%` 从而在 argmax(CAGR) 里赢过所有负收益配置。

**协议**(写死在模块里,改它 = 一次新搜索):搜索期 2024-04-09..2025-10-13 分 4 折
(train 6m / test 3m / step 3m);选参只看**池化训练窗**;头条数字只来自**测试窗**;
n_trials = 138;零对照从**策略自己的机会集**抽;最后留一段**全程未参与选择**的 holdout
(2025-10-14..2026-10-13)只评估一次。

**结果（搜索期）**——两个口径要一起看，它们回答的是不同的问题：

| 口径 | 它回答的问题 |
|---|---|
| **连续净值**（一个账户从头跑到尾） | 一个账户真赚到多少 —— **这个才是** |
| **池化测试窗**（WFV 协议统计量） | 训练窗选出的参数在测试窗上稳不稳 |

⚠️ **两个口径给出的优势差一个量级，读的时候顺序不能反**：

* **连续净值才是「一个账户真赚到多少」** —— 它的优势远小于池化口径；
* **池化测试窗是 WFV 协议统计量**：把若干个互不重叠的短窗 CAGR 取平均、每折重置资金，
  而短窗 CAGR 年化会放大 —— 且**均值常被单折主导**（历史实测：第一折远大于其余折）。
  所以池化口径的那个大数**不能当边缘读**。

连续口径下它**大幅跑输基准**，因为它**绝大多数时间在空仓**。这既是它的保护
（回撤小），也是它 CAGR 上不去的根本原因：**它几乎不在市场里**。

**零对照**：同止损止盈、同笔数、同机会集的随机入场 200 次/窗 —— 历史实测里
四窗有三窗落在随机分布之内 ⇒ 它的"战胜"不能与运气区分。

**一次性 holdout**（只评估了这一次）：相对基线仍然赢，但**绝对水平为负**、
且大幅跑输同期基准。⚠️ 该窗口此后已被 `capital` 台账记为**已消费**
（`research/holdout.py`）：再跑它不再算样本外，除非显式给理由。

**DSR**：按 §5 的选择偏差折算后，这个样本外 Sharpe 与噪声不可区分（样本极小 + k 很大）。

### 风险-收益前沿:高 CAGR 只有一种拿到的方式

搜索期池化测试窗（同一配置，仅改 `risk_per_trade`）：

**形状**：CAGR 随风险预算近似线性放大，直到某个档位后**转而下降**；同时 maxDD
单调变差。也就是说 —— **高 CAGR 只有一种拿到的方式：加杠杆**，而不是"选得更准"。
（具体数值不写进文档，见上：`python -m research.run_baseline` 再生。）

三点必须一起读:

1. **holdout 只在预注册的 sizing(risk=1%)上评估过。** 前沿上更高的杠杆档**没有**样本外
   holdout 证据 —— 去测它们就等于在 holdout 上选点,会把唯一那段干净数据花掉。
2. **8% 以上 CAGR 反而下降**,且 E[R] 从 +0.379(5%)跳到 +0.693(8%)、成交笔数从 22 掉到
   13~19:仓位被现金闸门与量能上限截断,定尺寸退化成「能买多少买多少」。高杠杆那一端
   **不是同一策略放大**,而是换了一种被闸门扭曲的行为,数字更脆。
3. 同杠杆下 v21 基线在同一档位也拿到同量级的高 CAGR（回撤同步放大）——
   **「高 CAGR」不是本 preset 的功劳**，杠杆给谁都是这个量级。

### 要跨过的那条线本身就不是干净目标

在同一条代码路径上重算 uptrend-pullback 的当前最佳:

| | 池化测试窗 CAGR | 同窗等权池基准 | 超额 |
|---|---|---|---|
| uptrend-pullback WFV 配置 | （见 `research/results/`） | （同上） | **大幅为负** |

也就是说这条线**跑输自己的基准 98 个百分点**。在这样一个窗口里比「原始 CAGR」,主要测的是
**beta 暴露**,不是选股能力。所以本比较同时报:池化/连续两个口径的 CAGR、同窗基准、超额、
平均敞口、逐折符号、随机对照两档(≥中位 / ≥p90)、DSR。

**原始 CAGR 仍然不是敞口中性的 —— 这一点我一开始说错了。** 所有族确实跑同一套 sizing
(risk 1% / mp 2),但**平均敞口不同**:信号多的族在场时间更长。实测基准线 7.4%、`str` 24.8%
—— 3.3 倍。所以表里必须同时看 **敞口** 与 **CAGR / 平均敞口**(每单位敞口的收益,粗口径的
资本效率度量):`str` 的 61.41/24.8 = 2.48 vs 线的 14.19/7.4 = 1.92,即**每单位敞口只高 29%,
不是 4 倍**。判据 ①② 按预注册的原始 CAGR 走(那是「哪个策略赚得多」的直接答案),但读数时
必须带上敞口一起看。

「相对 100% 敞口、日度再平衡的池指数」的原始超额则更不构成能力判据(5% 敞口的策略永远
跑不过 100% 敞口的指数)—— 那一列只用来回答「这里面有多少是 beta」。判 beta 还是选股,看的是
**随机对照臂**(同日随机票、同样止损止盈/笔数/机会集)与**对照臂**(见下)。

### 判据(预注册,四条同时满足才算战胜)

```
① 池化测试窗平均 CAGR > 基准线(同口径)     ③ 4 折测试窗里 ≥3 折为正
② 连续净值 CAGR       > 基准线(同口径)     ④ 4 折里 ≥3 折打赢随机对照(中位以上)
```
单看 ① 会被单折主导（历史实测：第一折远大于其余折，把均值抬起来）;单看 ③④ 又太松(牛市里随便
什么族都能有几折为正)。四条**同时**为假的概率远低于任一条。

### 「低估」的六种不同定义(这才是族与族之间的差别)

| 族 | 「低估」的定义 | 对手方 / 机制 | 与 uptrend-pullback 的分家处 |
|---|---|---|---|
| `str` 短周期反转 | 相对**自身 120 日包络**便宜 | 短期抛压后的均值回归 | 不要趋势、不看 MACD |
| `volshock` 波动率恐慌吸收 | 被**非信息性**冲击打到偏离,且波动率指纹已消退 | 被迫卖家(追保/赎回) | 看**两根 bar 的对比**(昨日暴跌 vs 今日波动率骤降) |
| `state_flip`(拆成 `sf_stress`/`sf_calm` 两臂) | 同一个量能读数在恐慌态=被迫抛售、平静态=没人出价 | 同一读数的两种对手方 | 状态从**许可门**升级成**语义门** |
| `cap` 巨量崩跌承接 | 相对**成交价值中枢**(惨跌前 20 日成交量加权均价)折价 | 被迫卖家 + 买方吸收 | 单根 bar 的内部解剖(收盘位置) |
| `xs_flow` 横截面流量折价 | 相对**同池**最便宜(不是相对自身) | 盘中流量冲击 vs 消息重定价 | 按折价深度优先**最弱的**,方向与它相反 |
| `lhr` 长周期折价 | 相对自身 120 日包络、按**自身波幅**标准化后位移异常 | 长周期反转(De Bondt–Thaler) | 120 日视野 + 只要求短趋势翻过来 |

### 两条对照臂(机制检验,不是参数扫参)

* `str_inv`:与 `str` **只差方向** —— 买 5 日涨得最多的(其余条件一字不改)。
  若两个方向都赚钱,说明抓到的不是反转,而是「被打过的票会弹」这种 beta。
* `cap_inv`:与 `cap` **只差 clv 的符号** —— 要求收盘趴在振幅下半段而不是上半段。
  ⚠️ 两份独立的提案对 clv 的读法**相反**:吸收族要 clv 高(有人接),恐慌臂要 clv 低(卖压持续)。
  这两条臂直接回答「clv 到底携带什么信息」。

### 沿路修掉的四个**会静默污染结果**的口径陷阱

| 陷阱 | 后果 | 修法 |
|---|---|---|
| `transform(...).shift(k)` 的 shift 是**全局**的 | 每只票第一行串到**上一只票**的末行(静默前视) | shift 移进 transform 里面 |
| 市场波动层在**行序**上 rolling | 算成「某只票连着 20 天」的标准差,不是市场波动 | 先在**日期轴**算完再映射回面板 |
| `dist_high252` / `ss_lo252` 要 252 根预热 | 评测窗从第 120 根起算 ⇒ **前 6 个月整段无信号**(实测第一折训练窗 0 个) | 换 `dd120` / `ss_lo120`(与评测起点重合,零样本成本) |
| 随机对照从**全窗口所有日**抽 | 信号在时间上**聚簇**(实测 `str` 单日最多 142 个)⇒ 比的是「选日子」不是「选股」 | 对照池 = 该族自己的信号日 × 该日可交易标的 |

### DSR 在本项目的样本量下**结构上不可达**(实测)

把 DSR 当通过门是行不通的 —— 实测(`metrics.deflated_sharpe_ratio`):k=600 时
E[max]≈3.11,而 n_trades=60 时 SE≈0.13,于是

| 门槛 | 需要的年化 Sharpe(k=600, n=60) | (k=150, n=60) |
|---|---|---|
| DSR ≥ 0.5 | ≈ 6.4 | ≈ 5.5 |
| DSR ≥ 0.95 | **≈ 10.9** | **≈ 9.7** |

而本仓库任一 preset 的年化 Sharpe 在 −0.50 ~ +2.10 之间 ⇒ **DSR ≥ 0.95 不可能达到**。
所以 DSR 只能当**相对惩罚**读(同一把尺下比大小),不能当通过门。这也意味着基准线自己的
DSR = 0.021 **不是它独有的问题** —— 这个样本量下所有策略的 DSR 都趋近 0。

### 结果（10 个族 × 4 条判据）

搜索期 4 折；基准线 = uptrend-pullback 的 WFV 配置。**连续** = 一个账户跑完整个搜索期
（不受折窗重置与年化放大影响，是最该看的那一列）。

表里**只留判据与机制结论，不留业绩数字**（§7：文档不写曾观测到什么；
数字用 `python -m research.family_search --run` 再生，落盘在 `research/results/`）：

| 族 | 四条判据 | 在**连续**口径下的判读 |
|---|---|---|
| `state_flip` 状态语义翻转 | ✓ | 四族里连续口径最接近基准线的那个（但仍**没有超过同窗等权池**） |
| `str` 短周期反转 | ✓ | 连续口径明显低于基准线；池化口径的高数值来自短窗年化放大 |
| `sf_calm` 平静态缩量阴跌 | ✓ | 连续口径低于基准线 |
| `cap_inv` 收盘趴低臂 | ✓ | 连续口径低于基准线 |
| `volshock` 波动率恐慌吸收 | ✓（勉强） | 判据④ 在 ≥p90 那一列**一折都没过** ⇒ "勉强"是真的勉强 |
| 基准线 uptrend-pullback | — | 逐折为正只有一半 |
| `str_inv` **买涨对照臂** | ✗ | 与 `str` 只差方向 ⇒ 方向本身**不能解释** `str` 的判据通过 |
| `xs_flow` 横截面流量折价 | ✗ | — |
| `sf_stress` **恐慌臂** | ✗ | 与 `sf_calm` 只差状态 ⇒ 状态门承重 |
| `cap` 收盘强臂 | ✗ | 与 `cap_inv` 只差收盘位置 ⇒ 收盘位置承重 |
| `lhr` 长周期折价 | ✗（样品不足） | 3/4 个测试窗**没有信号**（1 笔成交），按判据直接出局 —— 这是
「长周期折价 + 短趋势已转向」在这个池子上太稀有，**不是它被证伪** |

**这里每一行后来的命运**：同一批族在**曝光匹配**口径（把闲置资金按等权池计息）下
**没有一个创造价值**，而"低波动承重"这条线索被横截面因子探针**直接测量**推翻
（IC 方向在窗口对半切开后翻转）。详见 `presets.py` 的 `FAMILY_SEARCH_NOTE`
（负面证据必须与参数同时记录，§5）。

### 结论

**有 5 个族在预注册的四条判据上战胜了 uptrend-pullback 的当前最佳**(`str`、`sf_calm`、
`state_flip`、`volshock`、`cap_inv`)。**但没有一个是「更好的策略」**,理由四条:

1. **全部 10 族的超额都是负的**。它们跑赢了 uptrend-pullback，但都跑输
   「满仓持有这个等权池」。
2. **敞口不同，所以原始 CAGR 不是敞口中性的**：低敞口的族按 `CAGR/敞口` 算会好看得多 ——
   这正是必须做**曝光匹配**（闲置资金按等权池计息）的原因；匹配之后没有任何一族创造价值。
3. **DSR 全部 ≈ 0，而这是结构性的**：在 k≈600 这种试验次数下，DSR 达标所需的年化 Sharpe
   远高于本项目任何 preset 能给出的量级。DSR 只能当**相对惩罚**读，不能当通过门。
4. **唯一硬证据来自机制对照臂,不是收益本身**(见下)。

### 同一轮里被否掉的两个机制(负面结果)

| 被否的机制 | 怎么否掉的 | 剩下什么 |
|---|---|---|
| 「长下影 / 收盘强 = 抛压被吸收」 | 要求 clv 高的那一臂**几乎不交易**（敞口个位数百分比、成交寥寥）；反过来要求收盘趴低的臂反而有量 | 日线收盘位置**不携带**「有人接盘」的信息；若携带，方向与直觉相反 |
| 「赚被迫卖家(追保/赎回)的钱」 | 恐慌臂(放量杀跌)`sf_stress` 的 CAGR/敞口 **0.37** vs 平静臂(个股独自缩量阴跌)`sf_calm` **4.87** | 有效的是「**个体性缩量阴跌**」,不是「系统性恐慌抛售」 |

### 唯一被对照臂支持的机制:`str`(短周期反转)

把「买 5 日跌得多的」翻成「买 5 日涨得多的」(`str_inv`,其余条件一字不改)之后:池化
四条判据**全部不过关**（其中一窗还落在随机分布的低分位）。**所以方向是有意义的** ——
不是「被打过的票都会弹」这种方向无关的 beta。

已注册为 `preset us_reversal_dip_v1`。⚠️ 它仍然**跑输自己的基准**、
**DSR 与噪声不可区分**、**不得用于实盘**。

### 曝光匹配口径:把闲置资金按池子计息(这一节把上面的「战胜」推翻了)

一个平均敞口 7.7%~24.8% 的策略与 **100% 敞口**的指数比原始收益是**结构性不公平**的
(它大部分时间在持有零息现金)。但那不等于没法比,公平的问法是:

> 把闲置资金按等权池计息,只用这套信号做择时,**是否优于单纯持有那个池子?**

实测(`family_search.overlay`,前一日敞口加权,连续口径):

| 族 | overlay 超额 | | 族 | overlay 超额 |
|---|---|---|---|---|
| `idio_highvol`(放量对照臂) | **+5.46pp** | | `cap_inv` | −2.21pp |
| `sf_calm` | −0.70pp | | `str_inv` | −2.97pp |
| `idio_mktdown` | −1.24pp | | `idio_highrvol` | −2.99pp |
| `sf_stress` | −1.23pp | | `idio` | −3.25pp |
| `str` | **−8.25pp** | | `xs_flow` | −8.70pp |

**⇒ 在公平口径下没有任何族创造价值**,包括那个「战胜」的 `str`(−8.25pp)。唯一的正值是
4 组网格的对照臂、DSR 0.002 ⇒ 噪声。原始 CAGR 上的「战胜」在敞口被计息之后消失。

(池化口径的 overlay 会给出 +26 ~ +35pp 的正超额 —— 那是**构造差异**:窗口逐个年化再取平均,
且每折重置资金、被单折主导,和上面「原始 CAGR 的两个口径矛盾」是同一回事。以连续口径为准。)

### 机制隔离:三条条件里只有「低波动」承重

把两个幸存者的共同机制抽成显式族 `idio`(个股自己跌 + 市场没跌 + 不放量 + 相对自身 120 日
包络便宜 + 中期结构未坏),再逐条翻转做对照:

| 臂 | 连续 CAGR | 四条判据 | 结论 |
|---|---|---|---|
| `idio` 正题 | ✓✓✓✓ | — |
| `idio_mktdown` 市场**也在跌** | ✓✓✓④ | 「市场没跌」**不承重**（差异在噪声内） |
| `idio_highvol` **放量** | ✓✓✓④ | 「不放量」**不承重** |
| `idio_highrvol` 换**高波动**票 | ✗✗✗✗ | **低波动看起来是承重的** |

⇒ 这一轮把「个体性」与「不放量」两条否掉了,只留下**低波动**这一条线索。
⚠️ 这条线索在下一节被**直接测量**推翻了,不要当结论用。


### 因子探针:把所有族放在同一把尺子上量(这一节把上面的机制结论也推翻了)

`family_search` 的族都是**低敞口、带止损止盈**的,彼此可比,但与「满仓持有这个池子」不可比。
把问题退到最干净的形式:**满仓、月频再平衡、按一个因子排序选票**,与**同一流动性门下的等权
全池**比 —— 两者敞口都是 100%、同一个成本模型,所以差就是因子本身的贡献;没有敞口、择时或
现金拖累可以解释它。

```bash
$PY -m research.factor_probe --run                     # 三层检验:IC / 稳定性 / 逐月配对超额
$PY -m research.factor_probe --run --lo 2025-10-14 --hi 2026-10-14   # 后半段单独看
```

预注册的三条判据(写在模块 docstring 里,跑之前定死):① 秩相关 IC 的 |t| ≥ 2;
② 窗口在预注册的分界线上对半切开后,**两半 IC 同号**;③ 逐月**配对**超额 |t| ≥ 2 且 ΔSharpe > 0。
三条同时满足才算这个因子可用。

结论:**通过者为零**。三个具体的否证:

* **「低波动承重」被推翻** —— 这是上一节唯一剩下的线索。它的 IC 与 0 不可区分,而且把窗口
  对半切开后**符号翻转**;低波动一档跑输同池、高波动一档跑赢,与「低波动承重」相反。
  ⇒ 那一节的结论只在**搜索期那半段**成立。`family_search` 缺的正是这个跨半段复核。
* **「买被打下去的便宜票」不成立** —— 1 月反转与「距 120 日高点最远」两档都跑输同池;
  而且 `dd120` 的全窗 IC 方向是**越接近新高越好**,与「捡便宜」相反。
* **打赢全池的组合都是「更猛的篮子」** —— 动量/高波动那两档的年化波动是全池的两倍以上,
  ΔSharpe 只有约 +0.1,逐月配对超额 t 达不到 2;全窗看着很大的超额,切开后前半段有、
  后半段归零。

⇒ 这段数据上最接近「最优」的可得组合就是**买下整个池子**;14 个族与这些因子都只是用更曲折
的方式做同一件事,而且更贵。

### 唯一通过两半检查的效应不是选股,是「标的资格」

上面所有因子检验都在同门全池之内做,而全池本身是被**流动性门**(`amount60 ≥ 3e7`)砍过的。
把门放松(同一段代码、只改 gate)会得到一条**平滑、两半同号**的梯度:

```bash
$PY -m research.factor_probe --run --gate-scan   # 门梯度 + 两半同号检查(一次跑完)
```

* 梯度是**单调**的:门越低,收益越高;而且**回撤更小**(低流动性一端的 maxDD 明显小于高
  流动性一端),波动率几乎不变 ⇒ 不像杠杆效应,像流动性/非流动性溢价。
* **两半同号**,而且后半段(holdout)也成立 ⇒ 这是本次调查里唯一过了两半检查的效应。
* ⚠️ **但它不是「选股」**:在门**之内**按 `amount60` 分位选最低的一档,两半是混合的(一档
  赢一档输)⇒ 稳定的是**被门槛排除掉的那条尾巴**,不是「在合格池里挑更差的流动性」。
* ⚠️ **两件不能忽略的事**:(1) 面板是**今日 OI≥100 的快照**,尾部正是幸存者偏差最重的地方
  —— 「低流动性 = 更容易退市/被并购」意味着被淘汰的那些根本没进数据。本数据**无法**把
  「流动性溢价」与「快照幸存者偏差」分开。(2) 探针**没有成交模型**:它按收盘价记收益,
  而尾部标的正是 §4(e) 的成交量参与上限与 ATR×参与率滑点会咬得最狠的地方。
  ⇒ 这是一个**线索**,不是一个可交付的策略;要变成 preset 必须先做容量感知的仿真。

⚠️ 探针有自己的**探测下限**,必须说清:30 期样本只够抓到 |IC| 较大的因子,而真实股票因子
常落在 0.02~0.05 —— 本探针**结构上抓不到**它们。所以「不显著」≠「不存在」,只等于
「即便存在,也弱到扣不掉成本」。探针的有效性由 `tests/test_factor_probe.py` 钉住:
合成数据里**植入一个已知因子**要求必须被抓出来,再把同一个列**滞后一期**要求必须抓不出来。


### 结论与下一步

可以说的:相对 v21 基线,过滤器 + 退出几何在两个期间都改善约 **+5~10pp**,方向可重复。
不能说的:绝对收益为正。**holdout 已经被用掉了** —— 再做任何迭代都只能拿 in-sample 数字,
要么就得等新数据。审计已两次测出「在价格派生的 A~E 条件上做参数或排序层面的改动不产生
可证实的 alpha」,所以下一步的价值在**换信号源**,不在继续调参。

⚠️ 但「换到基本面/事件维度」这条路**用户已经排除**(只从价格行为里挖低估)。把这条约束和
上面的因子探针合起来读,当前状态是:价格行为这条路上,已知的因子(波动率、动量、反转、
距新高距离、流动性)在这段数据上**没有一个通过三条判据**,连「满仓持池」都跑不赢。
再往前走的合理方向只剩两个:① 换数据(更长的历史 / 更干净的 PIT 全域 / 日内数据),
② 承认这段窗口的答案是「买下池子」。两条都不该靠继续在同一份数据上调参来冒充进展。
